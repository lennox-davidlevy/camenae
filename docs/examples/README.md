# Attachment examples

These small documents contain **fictional test data**, not real customers, budgets,
or business plans. Each fits within the 64 KiB text-upload limit.

1. Open a chat and use **+ File → Upload from computer** to add
   [project-brief.md](project-brief.md), [budget.md](budget.md), and
   [meeting-notes.txt](meeting-notes.txt), one at a time.
2. Each upload is saved in the chat's inbox folder and automatically attached.
   Alternatively, use **Choose from workspace** for copies already there.
3. Send the questions below. The repository documents are not automatically added
   to your running workspace.

## Questions

> Using only the attached documents: what is the project codename, who owns it,
> what is the current launch date, and why did that date change? Calculate the
> remaining budget after the approved spending. Name one launch blocker and cite
> the document supporting each answer. What is the venue's street address?

For a snapshot check, send the files, then edit a workspace copy. The earlier turn
retains the content it sent; attaching again sends the current copy. Removing an
unsent chip should exclude that file from the next message, not delete it from Files.
